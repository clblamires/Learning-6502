## Registers
- A - The Accumulator
- X - X register
- Y - Y register

Each register stores a byte, a number between 0 and 255

## Opcodes

INX - Increment X (adds 1 to X register's value)

LDA - Load Accumulator

LDX - Load X register

LDY - Load Y register

TAX - Transfer accumulator to X

## More notes
The # operator means "actual number" instead of looking up a memory address

```
; load accumulator with the number 5
LDA #5
```
