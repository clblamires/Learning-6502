# What I need to install lol

This is pretty much just a list of the things I need to install on homebrew (macOS) to make things work:

## ca65 langauge support

Install this via VS Code's extensions

## homebrew stuff

- brew install cc65
    - ca65 assembles the 6502 code
    - ld65 links assembled code into finished product
    - cl65 coordinates the compiler/build process
- brew install sdl2 (required for Mesen NES emulator)
